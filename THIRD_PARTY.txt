Original emulator code: GPL-3.0-only (LICENSE).

Native SLEIGH and the HC12 language specification:
  Ghidra 12.1.2, National Security Agency and contributors.
  https://github.com/NationalSecurityAgency/ghidra
  Apache License 2.0 (LICENSES/Apache-2.0.txt).
  Built from the user's existing Ghidra distribution; no JVM is used at runtime.
  Source notices are retained in that distribution. Its source and license must
  accompany any redistributable binary package as required by the licenses.
  Local byte-memory, HC12 branch, indexed-word and exception patches apply only to build copies
  (patches/README.txt); the corrected language is compiled with native SLEIGH.
  The integration uses exceptions as the native SLEIGH error interface.

zlib:
  Jean-loup Gailly and Mark Adler, zlib license (LICENSES/Zlib.txt).
  https://zlib.net/zlib_license.html
  Linked against the system zlib package; package notices remain installed.

DSP56300:
  https://github.com/dsp56300/dsp56300
  GPL-3.0 (see the dependency's LICENSE.md), pinned in doc/dependencies.json.
  The native interpreter is built from a local checkout, patched only in build/.
  Original notices remain in the build copy and source checkout. Its asmjit
  component uses the Zlib license (source/asmjit/LICENSE.md). Other native source
  notices remain upstream. Corresponding source and dependency notices must
  accompany any redistributable binary package as required by their licenses.
  The reference core is integrated; combined MCU/DSP board boot remains pending.

Optional offline DSP assembly tool:
  https://github.com/xemu-project/dsp56300
  dsp56300-asm 1.0.0, Matt Borgerson, MIT license.
  Used only to assemble a document-derived NXP SPI prefix into ignored local
  references. It is not linked or distributed with the emulator. Its source
  and binary notices remain in the separately downloaded local tool package.

Manufacturer firmware, samples, manuals and product photographs retain their
original terms. They are private references, excluded from source commits and
not covered by the emulator's license.
