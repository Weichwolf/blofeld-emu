Original emulator code: GPL-3.0-only (LICENSE).

Native SLEIGH and the HC12 language specification:
  Ghidra 12.1.2, National Security Agency and contributors.
  https://github.com/NationalSecurityAgency/ghidra
  Apache License 2.0 (LICENSES/Apache-2.0.txt).
  Built from the user's existing Ghidra distribution; no JVM is used at runtime.
  Source notices are retained in that distribution. Its source and license must
  accompany any redistributable binary package as required by the licenses.
  Local byte-memory, HC12 branch, indexed-word and exception patches apply only to build copies
  (patches/README.txt); the corrected language is compiled with native SLEIGH.
  The integration uses exceptions as the native SLEIGH error interface.

zlib:
  Jean-loup Gailly and Mark Adler, zlib license (LICENSES/Zlib.txt).
  https://zlib.net/zlib_license.html
  Version/source archive identity is pinned in doc/dependencies.json.
  Built statically from the unmodified source archive; original notices remain
  in the build copy. LICENSES/Zlib.txt retains that source version's full notice.
  Source/notice availability for binary distribution remains governed by zlib's
  own license. No manufacturer assets are part of this dependency.

DSP56300:
  https://github.com/dsp56300/dsp56300
  GPL-3.0 (see the dependency's LICENSE.md), pinned in doc/dependencies.json.
  The native interpreter is built from a local checkout, patched only in build/.
  Original notices remain in the build copy and source checkout. Its asmjit
  component uses the Zlib license (source/asmjit/LICENSE.md).
  The build-copy patch also synchronizes AsmJit's host CPU detection with
  explicit std::call_once initialization; its original notices remain intact. Other native source
  notices remain upstream. Corresponding source and dependency notices must
  accompany any redistributable binary package as required by their licenses.
  The reference data-bus patch also corrects scaled selected-source S growth
  from DSP56300FM 5-13; numeric transfer operations and notices stay intact.
  The reference core is integrated; combined MCU/DSP board boot remains pending.

Native session audio client:
  PulseAudio 17.0 client, upstream authors and contributors.
  https://www.freedesktop.org/wiki/Software/PulseAudio/
  LGPL-2.1-or-later client code; individual source notices are described in
  LICENSES/PulseAudio.txt. The LGPL text is in LICENSES/LGPL-2.1.txt.
  libsndfile 1.2.2, upstream authors and contributors, LGPL-2.1-or-later.
  https://github.com/libsndfile/libsndfile
  LICENSES/libsndfile.txt retains the upstream COPYING file. Both source archives
  are pinned in doc/dependencies.json and built statically with dependency
  sanitizers. Original notices remain in the extracted sources. A local patch
  corrects callback types; see patches/pulseaudio-callback-types.patch.
  Corresponding sources, modifications and notices must accompany redistributable
  binary packages as required by their upstream licenses.
  Meson 1.5.2 is a pinned, uninstalled Python configure tool (Apache-2.0), not a
  runtime library. Its source package retains its own bundled dependency notices.

Optional offline DSP assembly tool:
  https://github.com/xemu-project/dsp56300
  dsp56300-asm 1.0.0, Matt Borgerson, MIT license.
  Used only to assemble a document-derived NXP SPI prefix into ignored local
  references. It is not linked or distributed with the emulator. Its source
  and binary notices remain in the separately downloaded local tool package.

Optional offline silicon test corpus:
  https://github.com/mborgerson/dsp56300
  Matt Borgerson, MIT license; pinned in doc/dsp-corpus.json.
  External MCPX GP silicon results, metadata and test programs stay in the local
  checkout with their notices. They are not linked or redistributed with the
  emulator and do not establish DSP56371/Blofeld hardware equivalence.

Manufacturer firmware, samples, manuals and product photographs retain their
original terms. They are private references, excluded from source commits and
not covered by the emulator's license.
