Original emulator code: GPL-3.0-only (LICENSE).
These notices include retained optional build/reference inputs. The current
display libraries do not link the core, compression or session-audio libraries.

Independent CPU12 runtime core:
  https://github.com/Weichwolf/cpu12
  GPL-3.0-only; corresponding source and notices remain in the pinned checkout.
  The source subproject uses its strict diagnostics and matching sanitizers.

zlib:
  Jean-loup Gailly and Mark Adler, zlib license (LICENSES/Zlib.txt).
  https://zlib.net/zlib_license.html
  Version/source archive identity is pinned in cmake/dependencies.json.
  The optional CMake build uses the unmodified source archive; original notices
  remain in the build copy. LICENSES/Zlib.txt retains that source version's full notice.
  Source/notice availability for binary distribution remains governed by zlib's
  own license. No manufacturer assets are part of this dependency.

Independent DSP56300 runtime core:
  https://github.com/Weichwolf/dsp56300
  GPL-3.0-only (the dependency's LICENSE; the same GPL text is in LICENSE).
  Configured as a pinned source subproject with matching sanitizers.
  Original source/setup notices remain in that checkout, including its
  THIRD_PARTY.txt attribution. The core has no dependency on another DSP
  emulator or JIT library. Corresponding source and its notices must accompany
  redistributable binaries as required by the GPL.

Native session audio client:
  PulseAudio 17.0 client, upstream authors and contributors.
  https://www.freedesktop.org/wiki/Software/PulseAudio/
  LGPL-2.1-or-later client code; individual source notices are described in
  LICENSES/PulseAudio.txt. The LGPL text is in LICENSES/LGPL-2.1.txt.
  libsndfile 1.2.2, upstream authors and contributors, LGPL-2.1-or-later.
  https://github.com/libsndfile/libsndfile
  LICENSES/libsndfile.txt retains the upstream COPYING file. Both source archives
  are pinned in cmake/dependencies.json. The native audio build uses static
  libraries with dependency sanitizers. Original notices remain in the extracted sources. A local patch
  corrects callback types; see patches/pulseaudio-callback-types.patch.
  Corresponding sources, modifications and notices must accompany redistributable
  binary packages as required by their upstream licenses.
  Meson 1.5.2 is a pinned, uninstalled Python configure tool (Apache-2.0), not a
  runtime library. Its source package retains its own bundled dependency notices.

Optional offline DSP assembly tool:
  https://github.com/xemu-project/dsp56300
  dsp56300-asm 1.0.0, Matt Borgerson, MIT license.
  Optional assembler for ignored local DSP references. It is not linked or distributed with the emulator. Its source
  and binary notices remain in the separately downloaded local tool package.

Optional offline silicon test corpus:
  https://github.com/mborgerson/dsp56300
  Matt Borgerson, MIT license; identified in doc/dsp-corpus.json.
  External MCPX GP silicon results, metadata and test programs stay in the local
  checkout with their notices. They are not linked or redistributed with the
  emulator and do not establish DSP56371/Blofeld hardware equivalence.

Manufacturer firmware, samples, manuals and product photographs retain their
original terms. They are private references, excluded from source commits and
not covered by the emulator's license.
