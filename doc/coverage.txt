Performance plan
Use a deterministic CPU/interpreter reference path and compare a DSP JIT against
it before real-time claims. Measure worst callback duration, underruns and output
under dense MIDI/polyphony/effects with host load, separately from sanitizer runs.
The current machine is an i5-1135G7 (4 cores, 8 threads); its sufficiency is not
established. Vulkan would require a separate equivalent DSP execution backend and
synchronization model. No GPU backend is currently planned or implemented.

saving-text physical LCD contexts, plus four fresh joint suffix restorations.
Independent original bytes/frames/clock-response geometry and complete font PBM/
PNG pixels are checked; shared warm reset/CCR/TIM and wire inputs remain explicit.
