The native half executes authored NOP/MOVEC/MOVE/JMP instructions through the
independent dsp56300 core after Mode5 reset. FM tableA-1 expectations are NOP1,
long immediate MOVEC/MOVE2 and long absolute JMP4 (3+lab1). It checks full
registers/flags, progress, unchanged emulated time, real M0/SR/LA initialization,
reset interrupt priorities and zero generated JIT blocks/executable bytes.
Changing a RAM opcode/operand changes the actual instruction and base count;
joint restore plus two fresh owners recover the original one-cycle NOP.

The separate generic DspCycleCache tests remain unchanged: sparse1024-byte pages
over24-bit addresses, zero sentinel, cold probes, references, deep-copy isolation,
move/reset behavior, bounds and comparison against dense independent values.
This legacy container is not the independent core's timing implementation.
SDK-only cycle-metadata/JIT-cleanup interfaces are no longer part of this target.

Both sanitizer profiles pass with zero compiler/format/tidy findings, hardened
ELFs and no foreign DSP symbols. See dsp-cycle-native-reference.json. Qualification
uses canonical object rules and generated link commands; legacy Ninja cache
repair is unqualified. Base counts do not establish interlocks, IRQ/bus waits,
physical cache timing, real-time callback safety or complete instrument startup.
