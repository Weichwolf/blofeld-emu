Original non-FM filter callback regression

original_dsp_filters loads unchanged program/lookup records from the pinned
private official Blofeld 1.25 archive. It runs standalone LP/BP/HP/Notch
12/24 dB callbacks under the native interpreter; it does not require a sibling
source build or replace emulator execution with a host filter.

Reproduce with the private archive at doc/Blofeld_Firmware_V1.25.zip:
  cmake --preset strict
  cmake --build --preset strict --target blofeld-original-dsp-filters-test
  ctest --test-dir build/strict -R '^original_dsp_filters$' --output-on-failure
The test skips explicitly if the archive is absent. Changed reference bytes or
missing instruction coverage fail. It writes only private run evidence under
build/strict/Testing/original-dsp-filters.trace; no manufacturer bytes are tracked.

The Python driver independently decodes the official MID and checks the exact
program/table hashes before the C++ firmware parser supplies native words.
doc/dsp-filter-reference.json pins both blocks, producer-model provenance,
branch counts and the digest of the 387 expected instruction starts. Coverage
is checked against the immutable original listing, not inferred from a
successful return or newly generated emulator output.

The direct integer oracle is adapted from the GPL-3.0-only producer fixture at
blofeld-src ee53815320ca32fe5bc4417a60e469dd68349db1. Interpolation, coefficient
preparation, fixed-point quantization and the second-order recurrence remain
separate from native instruction helpers. Named constants, explicit failure
paths and smaller functions follow the same project checks as other own code.
All filter results are produced by the original DSP instructions. The test
model only predicts outcomes; it never writes predicted outputs into the DSP.

The directed grid has 79872 single-section and 79872 two-section calls, covering
all 128 signed cutoff segments at six selected offsets, thirteen resonance
values, RM=0/1 and four rotating input patterns. It checks 3833856 section-output
samples, prepared coefficients, intermediate/final buffers, independent paired
histories, guards, retained parameters and return/cursor/mode state. The harness
executes its own setup, JSR and genuine returns with N0=1, linear modifiers,
initially unscaled status and seventeen readable in-place sample words. Native
per-call retirement is bounded at 512 instructions.

The previous separate producer replay at emulator code commit
6ff07ec6039291399f3b716444637908c4176788 independently exercised the same grid.
Its local receipt remains in doc/local/filter-cascades-current/verification.json
in the original working checkout; that imported fixture was not a routine test.
The current regression uses the official archive directly and a project-owned
fixture, without the former private assembler/snapshot dependency.

Qualification remains bounded non-FM callbacks. Wider parameter units, arbitrary
addressing/modes, FM/comb/PPG, voices, scheduling, physical timing, MIDI/audio,
complete-device boot and hardware equivalence remain unproven. The strict
original full-boot frontier is still reserved Y:002000.
