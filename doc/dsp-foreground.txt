Conditional original DSP foreground iteration

original_dsp_foreground enters unchanged P:0198 and executes through its actual
return-to-loop jump. No callee, instruction, CPU continuation or RTS is replaced.
The original primary/secondary MIDI readers, host-event drain, master output,
report queue, Effects Off copy/mix, note-event drain, active-entry service,
held-voice routine, scheduler tail and parameter smoothing execute together.
Their order and native stack depths have independent expectations.

32 contexts cover both RM modes, low/high pitch, noise endpoints, two mixer
profiles and serial/parallel filters. One original voice block per context is
checked with the existing independent oscillator/control/noise/filter/output
equations. The parent adds two actual call frames; older direct-call assertions
retain their original depths. The parent consumes the old voice bus before
rendering. Its earlier master call writes the declared zero previous block,
not the voice just rendered; no current-block playback is claimed.

CC7=0 leaves a pending transition from the native controller-reset value.
CC7=127, CC1=0, CC7=127 commits then reselects the same target. Independent
Q23 equations check the 63/64 one-pole MACR result, threshold250, exact target
snap/flag clearing, full A/B/X/Y, selected RAM and scheduler seed/tick/countdown.
There are 16 active and 16 settled outcomes; eight corrupted trace-word controls
must fail. All 127 original records remain hash-pinned and executable words
unchanged. Manufacturer bytes and detailed traces remain local.

Each context then enqueues running-status CC7=64 and executes eight more actual
foreground polls. The original reader consumes that message and stages the new
target. The real source/phase comparison returns to the loop while DMA remains
stationary: current volume, interpolation, seed, timer/countdown, voice histories
and master output must not progress. Independent stage order, RAM fields, native
frame, compare accumulator and zero flag check all 256 idle iterations. No host
writes advance the DMA cursor, repair a voice state or bypass the original gate.
This distinguishes responsive input polling from actual scheduled synthesis.

Setup declares sixteen readable part blocks (factory defaults for parts1..15),
Effects Off, one held entry, empty transport/event/report queues, previous phase0
and disabled DMA source0660. Original part reset, FX descriptor initialization
and event initialization run. These are fixture inputs, not recovered boot RAM.
The DMA source is not advanced or reported as a transfer. This establishes one
rendering foreground iteration followed by eight idle iterations, not continuous
DMA/arbitration, physical time, original
NoteOn allocation, full boot, live MIDI/audio or hardware equivalence.

dsp-foreground-ring.txt adds consecutive original foreground iterations with enabled
repeating DMA under an explicit untimed, paused-core serial interleave.
