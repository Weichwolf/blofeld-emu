Original DSP GPIO byte producer through IRQA

  cmake --build --preset strict --target blofeld-original-dsp-gpio-input-test
  ctest --test-dir build/strict -R '^original_dsp_gpio_input$' --output-on-failure

The optional test requires the local original 1.25 ZIP. It pins the archive/MID
and all 127 runtime records, then loads the final overlaid IRQA vector and the
complete unchanged GPIO input program. Record identities are in
dsp-gpio-input-reference.json. Firmware bytes and execution traces stay ignored.

An own native caller declares the mapped P/X context, linear modifiers, saved
registers, GPIO input modes and IRQA IPL1/falling-edge control. Logical external
observations supply each byte and its IRQ transition. Native vector/JSR, original
producer instructions and RTI perform the actual transfer; the host does not
write received data, set a queue result or replace CPU/frame state.

All 255 ordinary byte values execute, including F8 sampling the real reset
Timer2 counter. F4 belongs to the separate requested-word protocol and is
explicitly excluded. Independent byte<<16, modulo 128 cursor and untouched-cell
expectations check every actual ring store, all 128 cells after each byte, both
boundaries, timestamp, saved foreground state and genuine frame/return.
The original 182-word record is retained, not rewritten to a simplified receiver.

This qualifies a GPIO-producer component, not a native MCU sender or physical
MIDI wire. The preceding original initializer/DMA priority, true pin routing,
clock/synchronizer timing, F4 request/response, parser dispatch, full original
boot, normal MIDI/audio and complete update/recovery remain open. In particular,
the separate first-helper experiment's static high ACK observation is not made
a board default or a successful whole-request release here.

The separate original_gpio_midi integration (gpio-midi.txt) adds native MCU
senders, the original secondary-ring consumer/pitch callback and joint owner
snapshot replay under explicitly declared caller/wiring/interleaving profiles.
