DSP56371 GPIO ports C, D, E and F

Primary references
DSP56371UM table 2-8 (printed pages 2-9..2-13), chapter 6, sections 8.5,
9.5 and 10.7, and register maps in Appendix C.
DSP56300FM sections 2.3.3 and 9.6.2 for the core BCR reset fields.
Both reference PDFs are pinned in hardware/sources.json and remain local inputs.

Register map (DSP word addresses)
  Port C, 12 pins: X:ffffbd PDR, X:ffffbe PRR, X:ffffbf PCR
  Port D,  2 pins: X:ffffd5 PDR, X:ffffd6 PRR, X:ffffd7 PCR
  Port E, 12 pins: Y:ffff9d PDR, Y:ffff9e PRR, Y:ffff9f PCR
  Port F, 11 pins: Y:fffff5 PDR, Y:fffff6 PRR, Y:fffff7 PCR

PCR/PRR select each pin independently:
  PRR=0, PCR=0: disconnected
  PRR=0, PCR=1: GPIO input
  PRR=1, PCR=0: GPIO output
  PRR=1, PCR=1: ESAI (C), DAX (D), ESAI_1 (E), reserved (F)
RESET and external reset clear PCR/PRR and preserve observed external drives.
C/E/F preserve nonreset PDR latches; their cold contents and disconnected reads
remain unknown. Port D explicitly resets PDR to zero. Its disconnected register
reads use retained known latch bits, which do not qualify physical pad voltages.

GPIO data and pins
Input reads require explicit external observations. DspGpioDrive distinguishes
strong driven mask/levels, explicitly undriven floating pins and unobserved pins
(neither mask). Table 2-8 specifies internal pull-downs on PC0..11. Explicitly
floating Port C GPIO inputs therefore read low; disconnected pads can have a
known low voltage while their PDR bits remain undefined. Strong inputs/outputs
override the weak bias. Unknown output latches and peripheral-owned pads remain
unknown; neither can be qualified by a weak pull. This does not establish weak
bias for other ports. Withdrawal of an observation is not a floating assertion.
Overlapping driven/floating masks and levels outside the strong mask reject
without changing state. Peripheral output validation requires a strong drive.
Reset and copies retain both external drive and explicit floating observations.
This is logical weak/strong resolution, not analog resistance or timing.

Output values require
an explicit PDR write while configured output or the documented Port D reset.
No pull-up, NAND-ready level or unqualified peripheral waveform is fabricated.
The PDR
behavior does not qualify a future output latch after a write in a non-output
mode; those bits are conservatively marked unknown. Subsequent output-mode
writes qualify them. Silicon behavior for input/disconnected preload still
needs comparison, rather than assuming a retained or overwritten latch value.

Pad observations return known/level masks independently of GPIO register reads.
GPIO outputs expose driven/known/level masks and delegated peripheral ownership.
Opposed known external/output drives fail; unknown output latches cannot be
qualified by an external driver. Unmodeled ESAI-owned pads stay unknown. The
GPIO library supports explicitly masked reads and symbolic read-modify-write.
Native reference BCLR/BSET/BCHG require the selected previous bit for Carry and
change its output latch while preserving unselected output knowledge, including
unknown latches. BTST and bit branches read only the selected bit. An unknown
selected bit still fails; a whole-word MOVEP still requires the whole word.
GPIO configuration bits use the same hook and retain neighboring bits.

The hook models architectural GPIO state without inserting guessed pad levels.
It does not expose separate read/write bus phases or establish cycle timing.
Timer TCSR uses a separate full writable-word RMW path, including its W1C effects
(dsp-timers.txt). DMA and DAX also expose field-qualified bit accesses; their
unqualified status fields still fail. Other peripherals decline the hook without
side effects and
retain normal word accesses. A SHI FIFO bit test performs exactly one destructive
read; no preliminary read is used to construct a masked writeback.

Reserved upper register bits read zero; nonzero writes are conservatively
rejected pending hardware qualification. This does not establish harmless
reserved-bit write masking. F rejects simultaneous PCR/PRR selection per pin.
The F pin count and PD10 follow the register diagrams and signal table; section
6.2.4.3's prose says PD(9:0), inconsistent with its own PD10 diagram.

Port F and the BIU
The bus exposes BCR at X:fffffb. Its modeled reset is 1fffff, matching the family
manual's reset fields. Only the DSP56371-specific documented write 01ffff is
accepted. Port F bus accesses are rejected until that configuration is supplied.
After configuration, a whole BCR read fails because its read-only BBS bus-master
status is unobserved; writing a command cannot establish that status. Other BCR
configurations, BIU arbitration and wait-state timing are unsupported.
Core BCR state is restored on external reset; peripheral RESET clears GPIO modes.
This gate qualifies the documented logical setup, not measured BIU cycle timing.
Data sheet Rev4.1 Table25 (printed54) specifies Port F minimum high/low
pulse widths of6*Tc; note2 states PLL disabled and square-wave EXTAL. These
pin constraints do not define a six-cycle MOVEP cost or a BIU grant. Complete
PLL-enabled access-phase timing remains unqualified.

The original_dsp_boot regression checks that the executed published SPI prefix
and reached original stage retain the modeled BCR reset value. A separate original
refill-entry experiment without laboratory BCR initialization rejects its first
Port F access. This identifies an unresolved entry prerequisite, not a measured
stock-device fault or permission to weaken the gate (nand-pack.txt).

Checks
  ctest --test-dir build/strict -R '^(dsp_gpio|dsp_dax|native_dsp|original_dsp_boot)$' --output-on-failure
Tests exercise every implemented pin as input/output, reset/disconnected data,
latched outputs, masked/whole reads, contention and rejected-state preservation,
both serial-port mux tables, reserved F functions, register-space separation and
the BCR gate. Every Port C pin also checks explicit floating input/disconnected
bias, strong override, unobserved withdrawal, unknown output latches, contention
and reset. Mixed masks, invalid observation preservation, copies, other-port and
peripheral exclusions are directed cases. Native BRCLR waits on the weak low,
releases on a strong high and still rejects a subsequently unobserved input.
Synthetic native MOVEP/BCLR/BSET drives C output bits and samples E
inputs through the strict bus, then executes RESET and re-enables C outputs to
verify their nonreset latch. Native mixed-state tests check C (qq and EA) and F
(pp), previous-bit Carry for all four operations, postincrement once, BRCLR/JSET
on observed inputs, RAM short/EA fallback, FIFO read count, highest bit 23 and a
rejected bit-24 encoding. The DAX tests cover Port D's different reset latch,
per-pin mux, real native setup and peripheral output contention (dsp-dax.txt).
The optional offline fuzzer covers pads, masked GPIO, bits and resets; run it
only on an explicit user request.

Limits and original-firmware execution
No board pin wiring, NAND device, original ESAI stream, electrical/synchronizer
latency or stock-device equivalence is established. Mode-zero TIO
GPIO and timer clocks have separate coverage in dsp-timers.txt.
The original DSP still stops before reserved Y:002000 during its RAM-clear loop;
no loop is skipped or reserved memory write discarded to reach these GPIOs.
NXP section 3.1.1 warns against reserved-memory access and does not establish its
write effects. The GPIO tests are independent chip-model evidence, not evidence
that the original NAND loader or full board now boots.
