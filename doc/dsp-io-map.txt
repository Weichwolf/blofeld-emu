DSP56371 internal I/O decoder

DSP56371UM Rev2.1 tables3-7/3-8 assign the top128 X/Y data locations.
The primary PDF identity and URL are in hardware/sources.json. Every slot is
classified as assigned or reserved; program space and lower data addresses are
outside this decoder. There are86 assigned X slots and52 assigned Y slots.
IDR, BIU, instruction-patch and EFCOP registers remain assigned even when their
semantics are not implemented. An unsupported register is never an empty sink.

DspBus uses this selection for peripheral routing and memory-resource refusals.
Classification supplies no read value and no write acknowledgement. Reserved
reads/writes and unimplemented assigned registers keep their strict failures.
The map does not infer aliases between equal X/Y offsets.

Section3.1.4 explicitly excludes direct external memory access on this derivative.
The generic family manual's switchable/external regions do not establish an
external bus on the DSP56371. Section3.1.1 prohibits user accesses to reserved
memory; a reserved label alone does not specify physical read levels, hidden
latches, side effects or successful writes. Those semantics remain research.

Explicit disconnected-register experiment
A local candidate models every documented reserved slot as having no selected
write latch, with mandatory native address/word/PC event records. It never
returns read data, redirects to another register or accepts active-DMA overlap.
Directed ASan/UBSan controls cover both payload extremes at all256 destinations,
236 logged reserved writes, program-space exclusion, unsupported values, DMA
refusal and retained known neighboring registers. The candidate and its tests
pass their strict compiler/clang-tidy checks; they are not the default device map.

In a coupled original reset run with the prior SHI/cold-ESAI/conditional-NAND
hypotheses, one actual native reserved write selects this candidate. The original
runtime continues to an ESAI generated-clock timing refusal during a DMA/F2
cycle. No audio source, clock phase, read value or firmware patch is supplied.
All56,496 actual PDRF values and prior NAND output timestamps match the previous
candidate. The binary, references and43 frozen artifacts remain unchanged.
This narrows the next clock/scheduler task; it does not establish physical
reserved-address semantics, complete boot, audio or update safety. The manual's
reserved label and the generic simulator's acceptance are insufficient alone.
