Original DSP MIDI ring/parser and pitch callback replay

  cmake --build --preset strict --target blofeld-original-dsp-midi-test
  ctest --test-dir build/strict -R '^original_dsp_midi$' --output-on-failure

The optional original_firmware.py wrapper verifies the official ZIP identity in
downloads.json before execution; absent local firmware returns explicit skip 77.
The firmware, extracted records and run traces remain local. The test loads
the unchanged complete original P:0808 and P:0967 components and stored low X/Y
initial data into strict RAM. It does not execute original boot or its producer.
Component word-image SHA-256 identities:
  P:0808 / 351 words
    d89ff1a134a3a9684fdc3c8b66bd44fb81ad8621e3f3188ef5064f10a67fc288
  P:0967 / 1092 words
    603cd0a98101a15a7994a2d9f2d946f39890865ebf566f84161a7d9cf0a2dc5f

Declared caller context: OMR=000305, SR=c00300, linear M0..7, single block, omni or
one selected MIDI channel, clock ignored by the original setting. An own native
JSR harness calls both genuine ring consumers and the actual nested pitch-bend
callback; no host PC/register patch or successful callback stub is supplied.
Own input bytes are packed into the two original 64/128-word RAM rings. Their
otherwise unknown cells and adjacent guards are explicitly initialized, without
changing the board model's unknown-memory policy.

Independent MIDI 1.0 expectations use E0..EF, low seven bits then high seven bits,
center 8192 and the original field's fixed-point scale 1024. Protocol reference:
  https://midi.org/summary-of-midi-1-0-messages
All 16384 values per ring, running status, 256 orphan bytes, status replacement,
partial-message/clock interleaving and selected channels produce 34576 calls,
32873 genuine callbacks and 70430 input bytes. Matrix execution retires exactly
3101868 native instructions. Every field update, both five-word parser contexts,
ring consumption/wrapping, guards, nested return and final empty stack are
checked. These are fixed deterministic tests; no fuzzer runs.

Coordinated snapshots retain two partial messages. Two identical continuations
match whole CPU and all permitted mutable RAM; a changed continuation must use
the saved first byte and changed second byte. Six original callbacks complete.
Missing first cells on either empty ring expose genuine speculative reads at
P:0c5a / P:0c6a and X:2f80 / X:2d00 with PC/OMR. They fail before consumption,
field mutation or retirement; further execution and checkpoint capture reject.

The original_dsp_wire_bytes/pitch/checkpoint CTest cases execute unchanged original configuration,
vectors and input handlers from the complete P:2cd9 component through the actual
MS111 physical RAM alias. Logical TIO0 input and explicit CLK/2 edges supply
fixed 3249-edge 8-N-1 frames; native instruction/IRQ execution inserts no timer
clocks. This is a declared laboratory ordering, not calibrated baud or latency.

All 256 byte values produce 2304 original interrupt entries/RTIs, four ring wraps
and one actual clock timestamp. Connecting this actual queue to the original
parser/callback tests all 16384 pitch values with running status and three
interleaved clock messages: 32772 wire bytes, 294948 original IRQ entries/RTIs,
512 complete ring wraps and 16384 genuine pitch callbacks. Every sampled partial
byte, actual produced word/cursor, field update, foreground register restoration,
guard and reset-defined Timer2 clock timestamp is checked independently.
The checkpoint case captures inside the third data-sample ISR after its actual
vector and first handler instruction, with a live long-IRQ frame and incomplete
original MIDI message. Two identical remaining-bit suffixes reproduce the whole
CPU and watched RAM/timer state. Changing a later bit gives the independently
expected different value through the genuine callback; no queue or CPU state is
patched to manufacture the continuation. All three suffixes execute real RTI.

doc/dsp-midi-wire-reference.json pins the four original program/vector records
and exact fixed-case counts. The wrapper verifies the official archive, decoded
MID and records before native execution, and checks complete trace counters.
Missing private firmware is explicit skip77. Manufacturer bytes and run traces
remain local; the public fixture supplies only own setup and declared inputs.

The separate original_dsp_wire_download scope adds the complete original context
and download-command records. It sends actual TIO0 levels through the original
Timer0 setup/vectors/IRQs/RTIs and ring consumer. Firmware alone appends the SysEx
buffer and reaches its manufacturer dispatcher and runtime download routine.
Thirty fixed cases send 1050 bytes through 9450 IRQs/RTIs: 54 complete frames and
one abandoned prefix, 940 actual appends, 51 download entries, 96 P/X/Y stores and
six real launches to a downloaded own RTS with the original nested caller frame.
All four P/P/X/Y modes and both packet count commands retain exact own payload,
padding overshoot and other-bank/boundary guards. Wrong manufacturer/product/ID,
the distinct configured-ID and hardcoded download-ID checks, an interleaved F8,
delayed F7 and restart through a new F0 are checked without host buffer/PC patches.
The original path accepts both differing trailing values and an omitted one;
the latter reads the original M4 end marker. This does not establish a checksum
policy for other commands or physical update safety. The independently qualified
producer path retires 92 instructions per ordinary byte and two additional ones
for F8: 96602 for this matrix. The existing explicit 3249-edge laboratory timing
is retained; this scope does not qualify normal 31250-baud decoding.

Reproduce with the separately supplied official firmware archive:
  cmake --build --preset strict --target blofeld-original-dsp-wire-test
  ctest --test-dir build/strict -R '^original_dsp_wire_' --output-on-failure

This qualifies isolated producer and parser/callback fixtures. Physical DIN/USB assignment,
actual MCU/connector routing, interrupt/clock calibration, other MIDI
messages, controller mapping, voices and audio remain required. The complete
original DSP boot still fails at strict Y:002000. This test establishes neither
Desktop/Keyboard equivalence nor update/recovery or physical-device safety.
