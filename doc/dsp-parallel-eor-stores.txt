Parallel EOR and absolute address-register stores

  cmake --build --preset strict --target blofeld-parallel-eor-store-test blofeld-parallel-eor-producer-test
  ctest --test-dir build/strict -R '^dsp_parallel_eor_(store|producer)$' --output-on-failure

FM13-68/69,13-118/122 and Table12-14 define the128 encodings:
EOR X0/X1/Y0/Y1,A/B beside R0..R7 -> X/Y:absolute24. A separate predicate
admits these two-word stores without widening absolute reads or REP.

EOR changes only accumulator bits47..24. N follows bit47,Z tests only that
middle word,V clears,and E/U/C remain unchanged. The raw24 R source bypasses
limiting/scaling and has no S/L event. The move does not replace the ALU's
old operands. No host value/address substitution or new phase rule is added.

Per sanitizer profile,the base test has18432 windows,38 same-owner restores,
38 fresh-owner clones and8 guards. It covers all source/destination fields,
raw high bits,all256 CCR inputs,settled scaling fields and younger pointer
updates. Captured opcode/extension pairs survive backing-P replacement.
Whole state,stack/native counters,E1 cells,guards,F2 footprint and elapsed
periods follow independent expectations.

The separate1536-window test loads an old head into A1/B1 and a tail into
the ALU source before publishing the new R value. Both producer orders and
0/1/2 NOP gaps retain literal head/tail expectations,including equality while
the new head differs. Nonzero A2/A0 distinguish middle-word Z from full
accumulator zero. All three captured pairs survive replacement;28 cuts
restore and clone into fresh owners.

These are reference phase contracts,not measured silicon edges. Automatic
SC=1,immediate EOR and other parallel forms remain separate qualifications.
Full original instrument boot,MIDI/audio,storage/update/recovery,realtime
and hardware equivalence remain open.
