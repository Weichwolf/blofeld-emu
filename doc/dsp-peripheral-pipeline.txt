Native peripheral-store pipeline

The opt-in automatic_memory profile accepts immediate and X/Y/R/N/M register
MOVEP stores to short X/Y I/O. The selected high- and low-I/O encodings use the
real F2 opcode and, for immediate data only, its extension. Nine immediate and
112 register/port own encodings are pinned independently against the Freescale
assembler. No manufacturer program bytes are embedded in tests. Control, stack and accumulator store sources remain unqualified. Selected
native port reads are described separately in dsp-peripheral-reads.txt.

AG1 captures the fixed port address and actual extension where present, with no
fictitious AGU input or pointer update. AG2 advances that record without a
register write. Native E1 consumes the same F2 words and dispatches one actual
write through the strict owner. A register source comes from native CPU state;
no caller supplies its value. The selected reference order publishes the older
E2, samples register-store E1, then publishes younger AG2. This preserves old
R0 for a store adjacent to (R0)+ while retaining the actual increment through
retirement. Other memory forms retain their existing phase order. E2 publishes
the real PC/counters without repeating I/O or inventing a two-clock register stall.

The complete reported core footprint retains the short-I/O write and concurrent
P fetch. The arbiter classifies the idle-controller peripheral path separately
from RAM; memory_resource itself still refuses peripheral queries. One such
write and no other data use is admitted only with inactive DMA. Controller
writes, extra data access and active-DMA sharing remain unqualified. Selected
early port-read footprints use a separate automatic owner and logical phase;
ordinary explicit callers cannot claim that phase. This also applies to the explicit native-reference DMA admission
API. Resource admission neither supplies a register implementation nor performs
I/O: unknown/invalid actual writes still fail at their strict native owner.

Joint snapshots retain extension identity, phase records, actual effects and
peripheral state. Directed cases cover literal extrema, low X/Y registers, SHI
transmission without a repeated HTX write, captured/future code replacement,
trusted replay, register producer/younger AGU overlap, captured/future opcodes,
unknown Y ownership, reserved bits, failed simultaneous F2,
active DMA and the separate public native-reference caller.

The optional local document-derived SPI prefix is SHA-256 pinned. It enables
SHI and reaches three empty HRNE polls after43 reference clocks,16retirements
and38native diagnostic cycles. Actual SPI length input1 reaches native A0 and
the next address poll after53/19/47. Empty input keeps the original loop
running. These independently predicted checkpoints and fixture-wire limits are
described in dsp-peripheral-reads.txt. This partial document reconstruction is
not an authentic full mask ROM or normal instrument boot. Physical bus/ack
stages, further memory forms/branches/loops/IRQ/reset fill, active DMA,
reserved Y:002000 and the complete original Desktop/Keyboard acceptance
objective remain open.

model, including old R0 sampling before a younger postincrement. Readback is
checked after the quiet drain; immediate post-step peripheral visibility differs.
