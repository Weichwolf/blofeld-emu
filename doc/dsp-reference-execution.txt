Native DSP reference access continuation

DspMachine::begin_reference_instruction(DspReferenceExecution::access_boundaries)
starts one ordinary native interpreter instruction and returns its first pending
effect. advance_reference_access(ticket) performs that effect on the strict bus
once, then returns the next pending effect or retirement. reference_pending()
only inspects a healthy boundary. A loaded REP body without memory accesses can
retire during begin. Opcode, consumed extension, data read/write, specialized
peripheral bit operation and software peripheral reset are explicit effects.

begin_reference_interrupt uses the same explicit contract for an already eligible
interrupt. It separately admits both vector words and DspInterruptAcknowledge,
then the native vector instructions' actual effects. The request/priority and
absolute vector are retained at entry. Both words are latched before execution;
an absolute JSR consumes the captured second word as its extension. Entry retires
the existing fast/long vector operation, possibly two native instructions, rather
than a foreground instruction. It does not invent an interrupt latency.

This is a single-threaded, unclocked reference execution contract. Access ordinals
describe interpreter order; they are not silicon clocks or pipeline stages. In
particular, serial X/Y effects do not establish separate hardware cycles. The
existing clocked owner and automatic active-DMA timing rejection remain intact.
The ordinary instruction call still rejects eligible interrupt entry before any
fetch or acknowledgement. The separate interrupt call rejects absent, masked and
REP-deferred requests. The established atomic step path remains available.

The owner supplies an opaque ticket for the current effect. Default, foreign,
already consumed and old-generation tickets reject without consuming the real
pending effect. Reset and coordinated restore invalidate previously issued
tickets; query the restored machine for a fresh ticket. Tickets are process-local
capabilities, not serialized inputs or externally supplied arbitration proofs.

The adapter retains a fixed instruction-start native state and at most 64
records of admitted effects and decoder lookahead. Internal rollback stores raw
register values, derived AGU state, all sixteen stack cells, native REP/IRQ
continuation, counters and peripheral pacing targets. Compile-time checks require
trivial copying and at most 1 KiB; this build uses 464 bytes. It does not copy the
per-PC cycle vector or reconstruct the entire host dispatch cache per access.
Each attempt decodes its captured opcode afresh, including a loaded REP body;
partial/warm host dispatch cannot select a different instruction. Pure host cache
invalidations may remain; nominal reference costs use the captured opcode.
The adapter recomputes native arithmetic
from that state until the next unadmitted effect, checking the completed prefix
without repeating real bus I/O. Real reads retain their actual captured values;
real writes, resets and interrupt acknowledgements execute once. A source that
reasserts after its admitted acknowledgement is not cleared by recomputation.
A newer higher-priority source does not replace the chosen entry or get
acknowledged with it (FM2.3.2.6). A withdrawn source or changed priority rejects
at actual acknowledgement; dynamic cancellation after acceptance is unqualified.
Decoder lookahead retains its prior metadata
view, but a later consumed extension reads the then-current actual bus word.
Opcodes and consumed extensions can now be read into a fixed program latch
before native admission, keeping even register-only instructions suspended
after the actual read. Checkpoints retain this sampled word through DMA code
writes; admission consumes it without another memory read. The pending-word
primitive and separately enabled F1/F2 frontend are documented in
dsp-program-fetch.txt. The frontend retains actual later words across native
retirement, preserving P-data reads as separate accesses. It does not assign
physical phase clocks or silently qualify interrupts and loops.
Register state and native counters remain at the instruction or entry start while paused;
all architected updates publish together at retirement. Completed bus effects
remain visible between admissions. Reset aborts continuation through the existing
real reset path. Bounds, prefix mismatches and unsupported accesses fail visibly.

An immutable DspCheckpoint captures the native base, admitted prefix, pending
effect and actual bus/peripheral state together. Restore creates a replacement
owner and never replays already completed I/O. Admission failure quarantines the
core; a failed instruction cannot be captured or retried. Recovery requires a
previous trusted coordinated checkpoint. Observer callbacks remain read-only,
are not retained in these snapshots, and cannot act as admission callbacks.

Physical instruction-cache controls are outside the captured reference context.
PFLUSH/PFLUSHUN/PFREE/PLOCK/PLOCKR/PUNLOCK/PUNLOCKR reject in an access attempt
before their cache mutation or consumed address extension. The ordinary atomic
path retains its existing scope; this profile does not model a hardware ICache.

  cmake --build --preset strict --target blofeld-reference-access-test
  ctest --test-dir build/strict -R '^dsp_reference_access$' --output-on-failure

Own programs check actual FIFO consumption with its next word externally drained,
extension/code mutation, two restores of a pending store, exact postincrements,
bit-operation prior values, software reset, strict unknown/ROM faults and recovery,
ticket ownership, loaded legal REP bodies and interrupt/clocked-owner guards.
Separate interrupt tests hold the actual vector reads, acknowledgement and both
fast-vector stores. Two restores retain completed writes and FIFO data across
the two native instructions. Independent expectations cover relocated VBA,
first/second-slot and extended JSR, stack/PC/SR and actual RTI; missing second
words and withdrawn sources quarantine on actual admission and recover only
through a trusted checkpoint. Masked and REP-deferred entry remains rejected.
Later higher-priority SHI arrival preserves the selected timer and its separate
acknowledgement; an actual subsequent SHI entry leaves FIFO consumption to its
handler. Invalid native vector execution retains the acknowledged prefix and
requires a trusted prefetch restore before repair.
Explicit bank arbitration combines real pending native stores/loads with a held
DMA word: a later source overwrite must not replace its already captured value,
and two coordinated restores must deliver that value to the actual native load.

The optional original_dsp_boot regression executes the entire currently reached
13,015-instruction ROM/stage prefix using both ordinary steps and access
continuations under the same explicit pin interleaving. It compares every byte
of both pre-instruction traces and the final native counters/registers/stack;
all 94 stage words and every cleared mapped RAM pair have independent expected
values. The program remains unmodified and the executing SPI ROM supplies its
stage stores. Isolated branches suspend its loaded
single-word long-memory REP between the actual X/Y effects, both at the last
mapped pair and the next strict Y:002000 boundary. Two restores retain the real
completed X store without repeating it; the mapped Y store retires once with
independent R4/LC/zero expectations and the complete legacy native state. The
current unmapped Y effect fails only on actual admission, without retiring or
silently discarding the write; trusted restore recovers its captured prefix.
The unchanged main boot trace and an additional private access sidecar distinguish
legacy execution from these deliberate semantic-boundary mutations. This tests
the current strict map, not the physical chip's reserved-write or pipeline behavior.

  cmake --build --preset strict --target blofeld-dsp-boot-test
  ctest --test-dir build/strict -R '^original_dsp_boot$' --output-on-failure

Adopting consumers need matching project and prepared native SDK headers/libraries.
The SDK adds an interrupt-attempt wrapper using the existing fixed rollback and
cold dispatch. Both attempt/vector-active guards unwind on a yield or failure;
no partial native frame becomes a snapshot. The full ReferenceState declaration
is retained. The public effect variant now includes acknowledgement; rebuild
matching project and native SDK headers/libraries. Existing frozen consumer
bundles remain frozen until deliberately rebuilt.

Limits: trusted full checkpoints and code-map storage still allocate, native host
caches remain large, and yielding uses exceptions. Fixed internal rollback does
not establish allocation-free execution or real-time bounds. This path does not
belong in a real-time audio callback. IRQ-entry clocking, physical
pipeline/grouping/interlocks, elapsed stall clocks, dynamic deadline placement,
original full boot and audio, and real-device equivalence remain unqualified.
