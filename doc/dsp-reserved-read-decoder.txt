Reserved Y I/O read completion
=============================

The functional DSP decoder can explicitly configure a 24-bit virtual-instance
word for reserved Y I/O slots in DSP56371UM table 3-8. No RAM cell or peripheral
register is selected. This is a functional abstraction, not a measured silicon
read value. The ordinary NAND-backed Board selects nominal zero before reset.

DspBus::set_unselected_io_read_word defaults to nullopt. A configured word takes
effect only with functional_decode; strict and internal_writable_storage retain
their read refusals. Nullopt disables completion again. Reserved X, assigned but
unsupported registers, unknown RAM, vacant memory and invalid addresses retain
their existing guards. Peripheral bit operations are not admitted by this
word-read contract. Discarded writes do not initialize or change the read word.

Completed reads increment unselected_reads; resource lookahead does not. Trusted
chip/timeline snapshots preserve the configured word and observation count.
Reset preserves the selected virtual instance and clears the observation count.
An unselected read has no selected memory resource, including during actual DMA.
No guest code, AGU update, instruction or allocation routine is replaced.

The local connected original-firmware experiment recorded in
own-dsp-nand-reference.json first completed the real voice-selector loop and
emitted nonzero original DSP PCM with an explicit nonzero word. Its first
reserved load was overwritten before consumption along the observed path.
That observation motivates a decoder completion model; it does not establish
that an arbitrary reserved read is harmless or recover a physical bus value.
The frozen experiment is supporting evidence, not ordinary Board acceptance.

Reproducible affected checks (run each sanitizer profile separately):
  cmake --build build/strict --target blofeld-reserved-read-decoder-test
  ctest --test-dir build/strict -R '^dsp_reserved_read_decoder$' --output-on-failure
  cmake --build build/thread --target blofeld-reserved-read-decoder-test
  ctest --test-dir build/thread -R '^dsp_reserved_read_decoder$' --output-on-failure

The authored test independently transcribes all 76 reserved Y slots, checks
zero/all-ones/nonzero instance words and diagnostic/bit guards, executes actual
Y:(R1)+ loads and 24-bit cursor wrap, overlaps both real DMA phases, and restores
in-flight execution into fresh owners. Native instruction expectations supplement
snapshot comparison. These checks do not establish sustained audio, stereo slot
polarity, full boot, MIDI/USB, updates, real-time speed or either whole instrument.
