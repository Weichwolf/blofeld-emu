Normal SUBL/SUBR arithmetic and flags

DSP56300FM Rev. 5 pages 13-174/175 define SUBL as 2*D-S and SUBR as
arithmetic-floor(D/2)-S, stored in the destination accumulator. SUBL V includes
overflow in either the shift or subtraction, including cancellation of signs.
SUBR refreshes V from subtraction alone. Section 5.4.1.2 defines C as subtraction
borrow and L as sticky on arithmetic overflow. N/Z/E/U describe the result;
S changes only for an actual full-accumulator data-bus read. The normal-mode
regression now executes the independent core through actual Mode5 reset and an
untimed native owner. The retained legal SUBR source -2^55 checks that native
execution does not overflow signed-host arithmetic under UBSan.

The SUBL instruction caveat only qualifies C when the left shift did not
overflow. This profile calculates subtraction borrow, but does not claim a
DSP56371 silicon C result after shift overflow. Tests apply an independent C
oracle only where the manual qualifies it; all other CPU/flag/stack fields stay
checked in those cases. This declared limit is independent of observed mismatch
values. The tested path has SA=0 and SM=0, with three normal scaling modes.
This normal-mode test does not qualify sixteen-bit arithmetic (SA), saturation
(SM), pipeline timing, all derivatives or real-time audio. Additional SA=0 SM
checks are documented separately in dsp-saturation.txt. FV is the
DO FOREVER loop flag; it is separate from the arithmetic mode bits.

Deterministic checks (no fuzz or physical-device traffic)
  cmake --build build/strict --target blofeld-dsp-shifted-subtract-test --parallel 1
  ctest --test-dir build/strict -R '^dsp_(subl|subr|subr_host_overflow)$' --output-on-failure
Repeat with build/thread for the separate TSan profile; strict uses ASan/UBSan.

Each direction checks 3456 independent cases: twelve full 56-bit input values
crossed for source/destination, A/B destinations, three scaling modes and four
CCR seeds. Setup runs actual native instructions; no host register assignment
supplies the test result. A signed integer oracle has room for the mathematical
result and computes range overflow, explicit negative-odd floor division and
borrow separately from the core's bitwise implementation. Exact program progress,
retirement, all qualified flags, unselected registers and stack are checked.
SUBL has 1440 left-shift-overflow cases whose C bit is observed without a silicon
expectation. SUBR checks C in every case. Ten separate literal parallel-transfer
cases check old-value reads, growth, limiting and sticky S/L before ALU updates.

The saved own legal SUBR D=0,S=-2^55 regression previously aborted UBSan on
0-INT64_MIN in the native padded representation. The instruction must produce
wrapped -2^55 with V/L/C and its result flags. Independent SUBL D=0,S=1 also
caught spurious V; SUBR D=S=0 caught stale incoming V. Regression inputs contain
no manufacturer program bytes.

The independent integer oracle, value/scaling/status matrices and five directed
parallel inputs retain their tokens. Full native register equality includes every
stack entry and EP/SZ/SC. Twelve literal arithmetic/parallel forms independently
match the pinned official assembler without warnings; it is not a runtime
dependency. All six scopes pass under ASan/UBSan and TSan with eight qualified
independent archives/profile, strict compiler/format/tidy and hardened ELFs.
