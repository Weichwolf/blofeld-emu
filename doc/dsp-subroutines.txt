The automatic memory pipeline accepts short and long PC-relative BSR and RTS.
The original interpreter pushes the real following PC and SR,then pops the
actual return PC. RTS preserves the callee's current CCR. Return-target
prediction observes the stack without an SSH read/pop; native E1/E2 independently
executes and confirms each occurrence. A long extension is a signed relative
displacement,not an absolute address. Stack underflow/unsupported internal-stack
contexts and active-DO/call composition fail visibly.

Independent normal NXP software-model windows qualify nominal short BSR4,
long BSR5 and RTS3 clocks. The selected F1/F2/AG1/E1/E2 placements are reference
stages,not measured silicon sample edges. See dsp-subroutine-reference.json.
Its eight guarded streams also use ORI CCR; ORI remains unadmitted automatically.

The twelve automatic streams cover two initial CCRs,adjacent nested calls and
returns,sequential returned calls,short displacements -256/+255,a long backward
empty callee,and legal ANDI CCR immediately before RTS. Every period checks
literal whole CPU state,native counters and all16 retained stack slots.
All360 selected joint checkpoint cuts restore twice (720 suffixes). An explicit
own ROM preamble sets OMR300 and genuinely jumps into preloaded own RAM code;
no host PC rewrite or manufacturer firmware modification supplies execution.

Directed guards check all512 short-call fields,ten excluded Decode forms,nine
F2 width/value/owner refusals,and24 restored fault suffixes. Empty/full internal
stack and active-DO refusals retain literal full CPU/counters/all stack slots;
only older instructions actually due at the rejected period may retire.
These refusals do not implement physical stack-overflow handling or DO/calls.

Register-relative calls,extended-stack/overflow/interrupt/active-DO composition
and DOR Y1 remain unqualified. This component does not establish original boot,
authentic ROM contents,normal MIDI/audio,update/recovery or physical equivalence.
The original first-stage reserved Y:002000 boundary remains unresolved.
