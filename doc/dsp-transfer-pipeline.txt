Automatic native transfers and decoded address dependencies

The automatic_memory profile accepts selected register/short-immediate and
two-word long-immediate transfers, alongside its native memory/ALU forms.
Sources are literal data or X0/X1/Y0/Y1; destinations are those data registers,
full/partial A/B and R0..R7/N0..N7/M0..M7. Standalone MOVEC M0..M7 sources also
admit M0..M7 and full A/B destinations (FM13-131/Table12-14). Raw24 transfers
preserve CCR and bypass scaling/limiting; full A/B receives sign extension and
zero low24. Native conversion, arithmetic and modifier-cache updates remain in
the interpreter. Both documented W directions of modifier-to-modifier MOVEC
are admitted. Selected nonmemory SR writes and absolute24 data operands have
the separate scope in dsp-boot-instructions.txt. Other control/status/SSH
operands and unqualified accumulator sources fail contextually before actual I/O.

Decode derives instruction length from the captured opcode and skips an actual
extension as a separate instruction. AG1 retains that extension from the prior
real F2 buffer. E1 validates and consumes the native opcode/extension requests
from those captured words, publishes actual move destination fields and holds
the remaining native result. E2 publishes its true PC/native counters/ALU/CCR.
No host-injected literal, extra program read or replacement evaluator is used.
Modifier-source E1 publishes actual raw destination/cache fields; E2 retires
native counters/PC without replacing later fields or an older ALU's CCR. Own
cases cover all8 M sources,10 destinations,8 values,3 scales and4 CCR seeds;
84 snapshot cuts and14 explicit control/operand guards retain strict refusals.
An additional180 stream windows/1080 snapshot cuts check M chains, CLR flags,
full-accumulator stores, changed/identical M writers, disjoint register sets and
five upper bytes. AGU Decode holds follow the existing3/2/1/0 reference policy;
adjacent same-accumulator E1 stores retain their one source hold. Actual native
AGU consumes the newly published modifier caches; no host address evaluator is
introduced. REP body admission remains separately restricted.
The frontend bandwidth naturally leaves a slot between two-word instruction
starts; native instruction-cycle counters remain distinct from elapsed clocks.

FM A.2.4 places detection of address-generation dependencies at Decode. An
explicit R/N/M move destination in preceding AG1/AG2/E1 blocks a memory consumer
of the same register set. Ordinary implicit AG2 pointer updates do not rearm
that dependency. Older stages drain while Decode/F1/F2 hold, and real reference
time/timers continue. The selected distances match existing independent normal
NXP windows: register/short-immediate producers leave3/2/1/0 extra clocks for
0..3 intervening NOPs; long immediates leave2/1/0/0. Multiword gaps age real
clocks rather than just instruction count. Dual consumers check both register
sets, and multiple producers age independently. The exact frontend hold policy
is a declared reference order, not a measured silicon fetch/bus trace.

One-word X/Y memory loads may target R/N/M, including control-move M loads.
A native R destination supersedes its own earlier accepted AG2 update. Its
actual loaded value replaces the retained pipeline R value so later whole-result
publication cannot resurrect that old address value. Actual M/mask/modulo fields
publish together; subsequent native AG1 observes the new modifier behavior.
Reapplying an older load during restoration or retirement preserves a genuinely
later accepted AG2 value. A directed trusted-boundary case checks this ordering
without claiming an automatic elapsed-clock schedule for that explicit sequence.

Trusted joint snapshots retain extension identity, decode/address stages, native
move fields/caches, pending transfers and elapsed clocks. Captured code remains
immutable after F2; future reads see subsequent RAM code changes. Unknown real
extension fetches fail before CPU destination publication or elapsed success,
quarantine the owner and require joint restore before repaired native execution.

The directed cases include17 own NXP encoding pins, all R/N/M short/long
destinations, literal full/partial data fields, parallel ALU/register movement,
992 producer/register/gap combinations over X/Y memory spaces and high Mn bytes,
same-R load
precedence, actual modifier caches, dual/two-producer holds, multiword gaps,
snapshots, unknown-extension recovery and explicit unsupported-source guards.
Sixteen independent encoding inputs have zero NXP errors/warnings. A separate
intentional same-R destination input retains its expected assembler diagnostic;
it does not qualify physical AG2/E1 observation. No warning is disabled and no
manufacturer program bytes or tool binaries are redistributed.
