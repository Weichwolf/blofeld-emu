Original controller bytes to held-voice PCM

original_dsp_voice_midi supplies bytes to the actual primary DSP input ring.
The unchanged parser selects its original X:0936 single-part block; only the own
caller/declared sound fixture is relocated from the older X:1000 test context.
No manufacturer instruction, parser result or audio-state word is patched.

32 eight-block streams retain original oscillator, LFO, envelope, noise, filter
and master histories. CC7 values 127/0/1/64/96/127/32/0 exercise squared channel
volume, 512*v*v in Q23. This differs from the original reset level 7f0000 even
at value127. Subsequent CC1 value0 changes the pending destination and commits
the preceding volume through the original dispatcher. This is destination
switching, not qualification of the separate main-loop smoothing clock.

608 parser calls check exact input bytes, running status, three-call fragmented
input, a rejected channel, ring cursors, staged fields, pending target/destination,
actual volume/wheel fields and balanced native returns. Independent integer
models then check 256 voice/copy/mix/master blocks, 8192 actual finite DMA words
and 4096 ESAI pin-decoded stereo frames. Four deterministic corrupted trace-word
controls must fail; these controls are offline oracle checks, not fuzz traffic.
All 127 ordered original firmware records and voice instruction coverage remain
hash-pinned. Manufacturer bytes/traces remain local.

Own readable RAM, held-entry setup, native caller, finite DMA setup, paused-core
peripheral drain, HCKT/grants and receiver polarity are explicit test inputs.
No original NoteOn allocation, full boot, normal host MIDI/USB connection,
wall-clock smoothing, live audio or physical equivalence is established.
The upstream NoteOn reserved Y:ffffff read remains a strict separate boundary.

original_dsp_voice_midi_host also delivers one default eight-block stream directly
to AudioRuntime after each completed finite DMA/ESAI replay. All 19 parser calls
and 128 actual decoded frames reach the independent integer oracle and exact
private S32LE service monitor, including volume transitions. Four fixed corrupted
byte/state/master/serial trace controls and one monitor corruption must reject.
The generic sink stays outside modeled checkpoints; no frames are reconstructed
from traces for playback. See dsp-voice-pcm.txt for the declared 48000 Hz playback
rate, unqualified physical clock and private service isolation. ASan/UBSan and
TSan qualify this concurrent path separately. This remains own ring transport
and held-voice setup; external MIDI routing and normal runtime are still pending.
