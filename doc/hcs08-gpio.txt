Hcs08Gpio requires candidate_gt8a explicitly. GT Rev.1 chapter6 defines A/B/C
as8-bit, D as5-bit and E as6-bit ports, each with data/pull/slew/direction at
four-byte strides0000..0013. Reset clears all four register fields. Non-pin
positions shown read-only0 in the port figures have no modeled storage; this
candidate interpretation does not extend to other reserved registers.

Writes latch data even for inputs or pins owned by another peripheral. DDR1
reads the stored latch; DDR0 requires an actual resolved pad observation.
Missing/detached/unknown/conflicting observations fail with address/op/PC/CCR,
including when pulls are enabled: unspecified connectivity is not floating.
Driver descriptions expose only explicitly GPIO-owned pins, with input pulls
and intended steady-state output levels. Slew control has stored readback;
transition/settling/synchronizer timing is unqualified. The board owns net
resolution and alternate-function/pull-down policy. G/BDC/oscillator and other
registers refuse; enabling ADC/KBI/SCI/SPI/timers requires their own models.
Chip copies/moves preserve registers and detach pad callbacks; fresh board
owners reconnect them. Reset retains the existing physical pad binding.

The independent unit checks all20 register addresses with all256 byte writes,
reset states/non-pin fields, latch/input distinction, GPIO ownership, pull
resolution against known/unknown drivers, conflicts, detached copies and resets.
Partial CCR admission adds the original MOV immediate/direct, CLR direct,
LDA direct/extended, BIT/CMP immediate, BEQ, JSR extended and AIS forms. MOV
defines V/N/Z; JSR/AIS preserve flags. BEQ requires known Z. Independent native
classification and taken/not-taken/unknown-Z/descending-return-stack checks
retain unknown H/C rather than supplying fully known reset flags.
