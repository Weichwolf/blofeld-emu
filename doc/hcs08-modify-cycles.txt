HCS08 memory INC/DEC cycle reference

API: reference_modify_program_cycles extends the explicit CLR reference.
Older contracts retain their memory INC/DEC rejection.
Family Rev2 printed249/252: DIR/IX1 rfwpp(5), IX rfwp(4), SP1 prfwpp(6).
Native SLEIGH reads the old byte at r, suspends at its real STORE, resumes
that STORE at w and completes native V/N/Z updates. The f period performs
no bus access. No host arithmetic supplies a native result or flag.
H/I/C and unrelated registers retain their values and knowledge.
Unknown consumed data or indexed address fails visibly. Trusted joint
snapshots retain native temporaries, pending write and actual queue phase;
a fresh owner completes the captured result without rereading modified RAM.
Existing enum values and the CLR public checkpoint layout are unchanged;
recompile consumers under the same extended enum definition.
