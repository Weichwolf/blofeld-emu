Hcs08ResetSequence requires reference_bus_edges explicitly. It separates34
nominal reset-drive periods,38 further periods before sampling the external
RESET level, any continuing external hold and six reference entry periods. It
samples BKGD/MS at the reference resolved RESET rising boundary. Unknown drives
or mode inputs, a new assertion after rising and extra completed-reset edges
fail visibly. Copying the trusted owner preserves a partial reset phase.

These are reference bus edges, not measured silicon timing. GT16A/GT8A chapter5.2
uses internal bus cycles;2.3.3 and the appendix use fSelf_reset. The latter is
nominal8MHz ICGOUT, whereas reset BUSCLK is nominal4MHz. This wording/rate
qualification, approximate durations, input recognition and25ns MS setup/hold
remain distinct from the explicit nominal model. The caller owns actual clocks,
pad resolution, CPU admission, peripherals and BDC reset; no SRS flags are guessed.
The electrical drive-duration row is a minimum, not an exact counter guarantee.

After that sequence the separate native Hcs08::reset boundary clears H, sets
SP00FF and I, and retains the supplied healthy warm pre-reset A/X. Normal entry
reads the actual FFFE/FFFF vector. Explicit active_background entry precedes
any user-vector fetch (Family RM Rev.2 section6.4.5, printed96), including with
unknown vector bytes. The numerical active-reset PC is not established by the
pinned paragraphs: Hcs08State.pc_known is false, with canonical representative0.
Native fetch, disassembly, running-clock admission, READ_PC and GO refuse that
unknown PC visibly. Held BDC memory and non-PC register commands remain usable;
WRITE_PC establishes the actual known entry without defining unknown CCR bits.
The same six reference entry periods are retained; active-entry latency and
GO queue-refill microcycles are not independently qualified physical timing.
Opaque CPU checkpoints preserve PC knowledge. A supplied known PC0000 remains
a real executable address, distinct from the unknown representative. These
refusals report an emulator qualification gap, not a silicon-defined READ_PC or
GO error. Explicit power_on entry on a fresh CPU supplies no prior A/X. A and low X
remain unknown; H is known zero. Hcs08State.a_known/hx_known and opaque
checkpoints retain bit knowledge; set_state/state mask unknown representatives.
Warm reset preserves prior A/X knowledge. Faulted initialized CPUs still require
coordinated recovery, not a reset that hides partial execution. Vector/queue microcycles and prefetch
are not individually modeled. Failed native execution needs coordinated recovery.

Hcs08State.ccr_known records actual defined status bits. Reset establishes68
(fixed bits plus I); V/H/N/Z/C remain unknown. Unknown bits have a canonical zero
representative, never a known flag value. Native checkpoints retain this mask.
For partial CCR, qualified loads/stores/MOV/BIT/CLR define V/N/Z; comparisons
and ASL/ROL SP1 define V/N/Z/C; ADD SP1 also defines H. ROL requires known C.
BRSET7/BRCLR7 copy the memory bit to C. BCS needs C; BEQ/BNE need Z. BHI/BLS
need a resolved C|Z: both known, or one known set bit. Branches preserve flags.
BRA/AIX/AIS/JSR/JMP extended, TXS/NOP/BGND and PSHA/PSHX/PSHH/PULA/PULH/
TAX/TXA preserve knowledge. TAP defines all bits, CLI/SEI define I and CLC/SEC
require no incoming flags and define C. Other forms reject before execution;
prefix9E admits FE/FF/EE/E1/68/69/EB with the dependencies above. Fully known debug
states retain the complete existing native ISA. This qualifies the original
application RAM-clear prefix after warm reset, not the remaining controller ISA.
BDC PC/register changes preserve the mask. WRITE_CCR establishes all bits;
READ_CCR cannot serialize unknown flags into a fabricated successful reply.

Partial A/HX paths qualify register reads before native data effects. Immediate,
direct and extended LDA and CLRA define A; immediate LDX/CLRX define low X;
CLRH defines H; immediate/direct/stack-relative LDHX defines both index bytes. TPA
requires fully known CCR. Stores, comparisons, BIT and TAP require their actual
source register; indexed accesses, TXS, AIX and CPHX require full HX. Explicit
register-independent forms preserve masks. Other partial-register forms fail
with operation, address, PC and A/HX/CCR knowledge. This conservative admission
is a qualification gap, not a claim that silicon traps these instructions.
Fully known debug paths keep native ISA execution. BDC READ_A/READ_HX refuse
unknown bits; WRITE_A/WRITE_HX establish only their written registers. No guessed
reply is transmitted. SP is known after reset or supplied debug state.

The directed unit covers1280 input-mask combinations,2048 first-opcode cases,
256 second-opcode forms, native dependency/state/flag effects, direct-word
ordered reads/fresh restores/missing first-or-second data bytes, missing/wrapped
prefixes, actual cold vectors, warm unknown retention, fresh checkpoint restores
and actual BDC frames. No random/fuzz traffic is generated. The original cold
startup gate adds68 cases: four declared NVM trim profiles and absent/all16
explicit strap observations. Its fresh CPU receives no set_state input. Every
retirement checks that HX is known after original LDHX while A remains unknown
through6164; original LDA at6165 establishes A3. Twenty-two fresh joint suffix
replays include cold/pre-LDA boundaries. Power-on live ICGTRM80 is distinct from
per-unit FFBE; original code copies FFBE, requests ICGC1/2 and still stops at
unqualified ICGS1 (or earlier unknown straps/BGND). Electrical reset timing,
complete controller boot, other partial ISA forms and hardware equivalence
remain unqualified. The existing136-case warm trace remains a separate gate.

Native register values and A/HX/CCR knowledge commit together before the bus
retirement hook. Own LDA/LDHX immediate/direct observers check six successful/
failing-hook cases. A hook failure preserves executed facts and quarantines
the CPU; checkpoints still require return to a healthy completed boundary.
