TPM1 (30..34): MOD=0 free-running16-bit up-counter, BUSCLK prescalers1..128,
TOF read/zero acknowledgment, intervening-overflow invalidation and derived
TOIE/TOF interrupt request. No CPU interrupt delivery is implied. Either count
byte latches both; repeated same-byte reads hold the pair until the other byte
is consumed. Any SC/counter write resets coherency; counter writes clear count.
Divider phase is an explicit optional observation, never a reset default. Missing
phase faults on the first active edge. Counter writes/disabling discard phase;
re-observation requires a disabled timer. Live prescaler changes, modulo/channel
writes, PWM and synchronized XCLK/external clocks refuse before mutation.
Only qualified run-mode events/accesses are admitted; BDM/WAIT/STOP integration
and exact physical enable/reset/divider timing remain required.

COP owns SRS1800 and the existing write-once SOPT1802 behavior together. Enabled
deadlines are2^13/2^18 BUSCLK periods. Every SRS byte write services COP without
changing known/unknown reset causes. Batched advance returns only the consumed
prefix at its first reset request. Subsequent service/read/clock operations
refuse until explicit coordinated reset. Shortening across an already elapsed
threshold refuses rather than guessing internal divider history. Reset-source
bits are explicit board inputs, not inferred from device detection or reset-pin
state. Other system/reset registers and BDM/WAIT/STOP timing remain unsupported.
