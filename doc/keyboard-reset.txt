function beneath an own native JSR caller. It requires the local pinned original
1.25 and Keyboard1.4 archives; absent inputs skip77, changed inputs fail. No
manufacturer program bytes or disassembly are embedded in tests or published.

Native PB1 drives BKGD/MS, selecting active mode at the modeled reset rise.
The target completes separate drive/sample/hold/entry phases and applies native warm reset effects before any
user-vector fetch. Both candidate vector bytes are unknown, and the numerical
PC remains explicitly unknown until WRITE_PC. H becomes0;
SP becomes00FF; retained A/X and unknown CCR bits are checked. Actual BDC state
is C8. Target instructions remain held throughout. No callback supplies a canned ready result, decoded command, TCNT value or
native CPU continuation. GPIO reads resolve the actual modeled drivers and
declared peer inputs.

16-bit subtraction. Under declared CPU/IP30MHz, target4MHz and /4 TIM, both
phases measure239 counts: original code accepts, stores fixed9/12 and transmits

changing the seeded delay bytes or sending that command. This distinguishes
application versus earlier recovery timer inputs; neither original startup/caller
history is executed or inferred from the helper PC. The initial reset-held BKGD
release and the explicit later request each produce a genuine wire SYNC response.
