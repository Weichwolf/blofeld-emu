Independent DSP runtime integration

The regular Board/headless target uses Weichwolf/dsp56300, pinned in
dependencies.json. Blofeld memory decoding, peripheral state, wiring and device
clocks belong to this repository; CPU execution belongs to the independent core.

The current pin supplies automatic native execution through a pure known-code
view exposed by OwnDspIo, plus code revisions and event yields. Direct default-
Core/bus coupling is qualified; the coupled timeline below still uses captured
effects. See dsp-native-bus.txt for exact evidence and pending native scheduling.

OwnDspMachine owns CPU, bus, interrupts and clocks. OwnDspFetch/OwnDspTimeline
coordinate captured program fetch, actual native effects, publication and DMA.
McuDspRuntime couples MCU IPBus periods with DSP periods and external events.
Callbacks and checkpoints preserve the declared owner/event order; unknown
accesses and invalid ownership remain visible errors.

The ordinary original1.25 case starts from actual reset, downloads DSP code
through native MCU/SPI execution, reads declared NAND cells and produces original
DSP PCM after MIDI input. The current accepted interval is bounded; full normal
startup and every documented instrument function on both profiles remain open.
See nand-board.txt, nand-read-handoff-reference.json and coverage.txt.

Instruction/fetch/DMA/IRQ/checkpoint tests are supporting component evidence.
Recent specific scopes include dsp-dispatch-cache.txt, dsp-clocked-wire.txt, dsp-modifier-native.txt,
dsp-dma-callback.txt and dsp-interrupt-owner.txt. Each reference manifest states
its source/input identity and limitations; replay alone is not full acceptance.

The runtime already excludes the foreign DSP executor. Remaining legacy test
migration/dependency removal is separate work. Replace transitional OwnDsp names
only after that removal, consistently across implementation/build/docs. There is
no intended permanent alternate backend or backend-selection interface.

The VSL test now runs directly through the independent CPU and board bus, using
authored literal instructions without the former runtime assembler. Its 9,216
value/scaling/status/source/insertion/address vectors retain the independent
memory oracle and now compare the complete architectural registers and stack.
REP/modulo and contextual bus/encoding refusals remain covered. PFLUSH now
executes rather than satisfying the obsolete unimplemented-instruction guard.
Both sanitizer profiles pass; see dsp-vsl-reference.json. Other legacy fixtures
still require migration or explicit retirement of their obsolete contracts.

CMPM's 16,902 independent magnitude/flag cases and immediate CMP's 256 signed
cases now use that same independent runtime. Actual F2 retention after a backing
program change, separate native ALU/PCU publication, complete register/stack state
and checkpoint capabilities replace the obsolete comparison adapter phases.
This migration exposed and corrected minimum-magnitude V/L flags in the pinned
core. See dsp-cmpm.txt and dsp-compare-native-reference.json for scope and limits.
