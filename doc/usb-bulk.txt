Full-speed bulk NISOF compatibility model

S12USB20D6E2FV1 V01.03 defines NISOF for high-speed isochronous IN and
requires zero for physical2/3 in table3-10. Original1.25 instead initializes
its bulk endpoints with raw820008d1/820008c1 (NISOF=2). The functional model
retains those bits but does not apply high-speed isochronous PID rules to
full-speed bulk. This is an explicit decoder hypothesis, not measured silicon.
Nonzero interrupt/isochronous fields still fail; no RAM or descriptor is patched.
Speed, endpoint selection, configuration, size, ownership, knowledge, halt and
ordinary bulk PID/ACK rules remain enforced.

usb_bulk_fields covers32 direction/size/NISOF combinations, duplicate OUT,
occupied NAK, firmware buffer release, lost IN ACK, immutable retransmission,
DATA0/DATA1 advancement, raw-field retention and three interrupt guards.
The identical new test object linked against the previous MCU archive fails
at its reserved-NISOF check; the corrected archive passes.

original_usb_bulk runs conditional unchanged MCU startup/reset/configuration,
then the production probe/runtime and real loopback USB/IP. Every332-byte
DEVLIST and320-byte IMPORT reply matches independent layout and ROM fields.
Two USB-MIDI OUT notes enter the actual original ISR: passive GPIO observation
captures exactly six MIDI bytes. The original primed IN ZLP is ACKed and its
real ISR runs. The bulk interval retires426 instructions/three IRQs and returns
through original RTI/main WAI. MCU NVM remains unchanged. The reset regression
also checks both original packet admissions and IRQs without guest execution.
