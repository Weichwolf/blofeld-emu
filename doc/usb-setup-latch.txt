Retained application SETUP bytes

S12USB20D6E2FV1 V01.03 section3.1.17 guarantees USTB validity only while
SETUP=1. Original1.25 acknowledges that flag before LDAB7,X reads USTB at
033f/PCbc3d. This is a documentation/firmware conflict, not physical validation.

The functional compatibility model separates byte knowledge from pending IRQs.
Only an accepted application-directed eight-byte SETUP supplies the latch.
SETUP/SETOVR W1C acknowledges events without erasing those known bytes. Bad CRC
cannot replace them. A subsequent accepted application SETUP replaces all eight;
replacement while pending still asserts SETOVR. Copies retain their own bytes.
Automatic standard requests do not populate this application latch or fabricate
SETUP IRQs. External/module/endpoint reset invalidates its knowledge; reads then
fail visibly until another accepted application request. Post-reset bytes are
never synthesized as zeros. This contract is an explicit functional hypothesis.

The native regression requires ordinary/overrun lengths0/1/8/9/17/18/65535,
independent clamp/paired-copy/serial-field and retained-load flag expectations,
actual DATA1/ACK and completion IRQ/RTI/WAI, sixteen joint pre-read restores,
three complete ROM descriptor captures, two probe restores and three real
TCP DEVLIST/restore-retirement paths. Retirements are counted outside snapshots;
saved prefixes are not newly executed instructions. MCU NVM must stay unchanged.

Focused optimized gate:
  cmake --build --preset release --target blofeld-original-usb-reset-test blofeld-usb-event-test blofeld-usb-configuration-status-test blofeld-usb-functional-halt-test blofeld-usb-endpoint-reset-test
  ctest --test-dir build/release --output-on-failure -R '^(original_usb_reset|usb_events|usb_configuration_status|usb_functional_halt|usb_endpoint_reset)$'

These are conditional untimed MCU fixtures. They do not establish common-clock
enumeration, kernel attachment, bulk MIDI, Spectre, DSP audio or physical timing.
Original bulk NISOF remains strict. No firmware patch or host-supplied descriptor
replaces original execution; firmware/ROM assets and run traces remain local.
